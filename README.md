# 🪙 Srimongal Trading View

Srimongal Trading View হলো একটি পরিষ্কার এবং শক্তিশালী ক্রিপ্টো ট্রেডিং চার্ট প্ল্যাটফর্ম। এটি TradingView উইজেট ব্যবহার করে লাইভ **Bitcoin (BTC/USDT)** সহ অন্যান্য মার্কেটের চার্ট প্রদর্শন করে। এই প্রজেক্টটি বিশেষভাবে স্থানীয়ভাবে (locally) চার্টটি দেখার জন্য তৈরি করা হয়েছে।

---

## ✨ Key Features (মূল বৈশিষ্ট্য)
আপনার দেওয়া HTML কোড অনুযায়ী, এই চার্টটির মূল বৈশিষ্ট্যগুলি হলো:

* **Dark, Modern UI:** ডিফল্টরূপে ডার্ক থিম ব্যবহার করা হয়েছে (`background: #0b1220`)।
* **Watermark Included:** চার্টের কেন্দ্রে একটি হালকা **"Srimongal Trading View"** ওয়াটারমার্ক যোগ করা হয়েছে।
* **Fullscreen Chart:** চার্টটি স্ক্রিনের সম্পূর্ণ উচ্চতা এবং প্রস্থ জুড়ে প্রদর্শিত হয়।
* **Default Symbol:** ডিফল্টরূপে **BINANCE:BTCUSDT** চার্ট লোড হয়।
* **Included Study:** চার্টে ভলিউম (Volume) স্টাডি যোগ করা আছে।
* **Browser Ready:** সরাসরি ব্রাউজারে কাজ করে (কোনো লগইন বা এক্সটার্নাল হোস্টিং প্রয়োজন নেই)।

---

## 💻 Run Locally (চালানোর পদ্ধতি)

এই চার্টটি আপনার নিজের কম্পিউটারে দেখার জন্য নিচের ধাপগুলো অনুসরণ করুন:

1.  **Download / Clone** এই রিপোজিটরিটি ডাউনলোড করুন:
    ```bash
    git clone [https://github.com/](https://github.com/)<your-username>/Srimongal-Trading-View.git
    cd Srimongal-Trading-View
    ```
    *(নোট: `<your-username>` এর জায়গায় আপনার GitHub ইউজারনেম ব্যবহার করুন।)*
    
2.  **Open the Chart:** ডাউনলোড সম্পন্ন হওয়ার পর, ফাইল এক্সপ্লোরার বা ফাইন্ডারে গিয়ে `Srimongal-Trading-View` ফোল্ডারটি ওপেন করুন। এরপর **`index.html`** ফাইলটির উপর ডাবল-ক্লিক করুন।

আপনার ডিফল্ট ওয়েব ব্রাউজারে লাইভ চার্টটি খুলে যাবে।

---

## ⚙️ Configuration (সেটিংস পরিবর্তন)

আপনার প্রয়োজন অনুযায়ী চার্টের সেটিংস পরিবর্তন করতে, **`index.html`** ফাইলটি আপনার পছন্দের কোড এডিটরে (যেমন VS Code, Sublime Text) ওপেন করুন এবং `<script>` ট্যাগের ভেতরের অংশটি পরিবর্তন করুন:

| সেটিংস | `index.html`-এ পরিবর্তন করুন | বর্তমান মান |
| :--- | :--- | :--- |
| **Symbol (কয়েন)** | `"symbol"` | `"BINANCE:BTCUSDT"` (BTC/USDT) |
| **Interval (ইন্টারভ্যাল)** | `"interval"` | `"60"` (১ ঘণ্টা) |
| **Theme (থিম)** | `"theme"` | `"dark"` |
